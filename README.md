## What this project includes
- **9 classes** total (meets “7+ classes”)
- **2 abstract classes:** `Person`, `HospitalStaff`
- **2 interfaces:** `Schedulable`, `Payable`
- **Concrete classes:** `Patient`, `Doctor`, `Nurse`, `Appointment`, `Billing`, `HospitalMain`
- Demonstrates:
  - Encapsulation (private attributes + getters/setters)
  - Inheritance (IS-A)
  - Constructors with parameters
  - Method overriding
  - `this` and `super`
  - Main class printing output

## How to run
